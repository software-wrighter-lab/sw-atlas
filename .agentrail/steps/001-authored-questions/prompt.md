Build the frozen evaluation sets, before the matcher is measured and long before any training row exists. Every row carries text, expected answer, intent, split and origin. Rows drafted by this agent are origin Teacher and status unconfirmed: they are NOT a frozen set until the repository owner has passed over them, and the file records what he confirmed and when. Freeze each set with a committed hash, and write the leakage check now -- by hash and by 8-gram overlap against training rows -- so it fails the build the day a frozen row leaks into training. Draft in reviewable batches, covering every resource kind and every intent in proportion to the corpus rather than to what is easy to write. Exit: the sets committed with their hashes, the leakage check with a test that fails on a seeded leak, and a count of what is confirmed against what is still awaiting review.
