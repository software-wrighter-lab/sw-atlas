The blog draft _drafts/saw-atlas-typed-decisions.md (Saw #12, publishing 2026-09-20) cites five papers that give this plan published grounding it was missing, and the plan should carry them where a future session reads them rather than only in a post. Add a references section to docs/needle.md and cite each paper from the section it justifies. (1) Sukhbaatar et al., Augmenting Self-attention with Persistent Memory, arXiv:1907.01470: the feed-forward sub-layer can be merged into attention as learned persistent key-value pairs and removed without degrading performance. This is the strongest support for the no-FFN decision and it also names the principled fallback if capacity is missing -- persistent memory slots, not an MLP. Record the finding that Needle's config declares num_memory_slots = 64 and plumbs it through train.py and finetune.py but never uses it in architecture.py, so the idea is available and unexplored. (2) He and Hofmann, Simplifying Transformer Blocks, arXiv:2311.01906: 15 percent fewer parameters and 15 percent faster training by removing skip connections, value and projection parameters and normalization. (3) Reimers and Gurevych, Sentence-BERT, arXiv:1908.10084: the bi-encoder shape behind the A1 and A2 retrieval head. (4) SetFit, arXiv:2209.11055: the named floor baseline for A1. (5) Guo et al., On Calibration of Modern Neural Networks, arXiv:1706.04599: modern networks are systematically overconfident and temperature scaling is a cheap correction -- name ECE and temperature scaling explicitly in the calibration saga instead of leaving the method unspecified.
