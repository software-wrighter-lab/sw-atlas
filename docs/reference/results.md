# Results

One row per measured run. A number reaches this table only if someone can
regenerate it with a command in this repository, or if it was measured
elsewhere and says so. Transferred rows keep their origin beside them,
because a number measured on nine campus places is not a number measured on
643 artifacts and nothing here should let a reader confuse the two.

Written by hand at the close of Saga 1 with the rows this repository
inherited. From Saga 2 onward, `just eval` appends its own.

## The bar

> A tier ships only when it beats the tier below it, measured on the same
> held-out questions, and only while it stays inside its memory and latency
> budget.

Concretely, adopted unchanged from `moe-microscope` and stated so it can be
failed: **+20 points of paraphrase destination accuracy over the stronger
matcher, +20 points of intent accuracy, and unsupported recall at or above
0.8.** The champion today is a deterministic keyword matcher, and every
trained docent so far has lost to it.

that corpus and the matchers still won.

Every relation in the corpus is `Declared`: a person wrote it in front
matter or a catalog field. Nothing here is `Derived` or `Teacher` yet, so
no metric in this table can be distorted by a model's guess — which will
stop being true in Saga 5, and is why `Provenance` exists.
